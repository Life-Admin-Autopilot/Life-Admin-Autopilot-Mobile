# Mo mascot — image-gen prompts (optional richer poses)

Generate these to deepen the Alan-style match. **All are optional** — the redesign ships
without them using the existing assets. Generate as **1024×1024 PNG, transparent
background**, then drop into `assets/images/mascot/` with the filename in each heading.
I'll convert each to `.webp` and wire it in.

**Consistency rules for every prompt** (so all poses read as the same character):
> A 3D rendered cute fluffy beaver character named "Mo": warm chocolate-brown fur, large
> cream-colored belly, big glossy black oval eyes, small dark nose, tiny rounded ears, a
> flat paddle tail. Pixar/Blender soft-render style, soft studio lighting, subtle ground
> contact shadow, friendly and approachable. Transparent background, centered, full body
> unless noted. Consistent proportions across all images.
